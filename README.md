## ✨ Features

- 🗞️ **Live headlines** — fetches and renders current news articles.
- ⚛️ **Component-based UI** — built with React for a smooth, single-page experience.
- 📱 **Responsive** — reads well on phone and desktop.

## 🛠️ Tech stack

`React` · `React DOM` · `Create React App` · `Testing Library`

## 🚀 Quick start

```bash
npm install
npm start        # http://localhost:3000
```

```bash
npm run build    # production build
npm run deploy   # publish to GitHub Pages
```
